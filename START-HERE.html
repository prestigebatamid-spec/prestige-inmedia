Before uploading

Use a new Custom PHP/HTML website on Hostinger. Back up any existing website first. This package is for file-based hosting, not Website Builder.

Six steps to launch

  1. Enable SSL and select PHP 8.2 or newer with PDO MySQL and cURL.
  2. Create an empty MySQL database and user in hPanel.
  3. Upload the contents of public_html into your website's public_html folder.
  4. Upload prestige-private beside public_html. Copy config.example.php to config.php. Fill in your domain, database credentials and two different random secrets of at least 32 characters.
  5. Visit your-domain.com/#setup. Enter your setup token and create your administrator account.
  6. Test a client account, brand profile, enquiry and creative request. Sign in as administrator to deliver work, then approve it from the client account.

Folder placement

your-domain.com/
├── public_html/
│   ├── index.html
│   ├── .htaccess
│   ├── assets/
│   └── api/
└── prestige-private/
    ├── config.php  ← create from config.example.php
    ├── bootstrap.php
    └── worker.php
No default login. Your administrator email and password are created during setup. The installer locks after the first administrator is created.

Turn on automation when ready

The website saves requests and supports manual delivery immediately after setup. To automate production, connect your Claude/Canva workflow using the webhook settings and enable prestige-private/worker.php as a Hostinger PHP cron job.

See AUTOMATION.md for the exact request and callback formats. Third-party generation, social publishing and ad execution require their own connected workflow.
